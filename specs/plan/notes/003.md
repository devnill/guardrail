# 003: Create python.json stack

## Implementation Notes

### Detection patterns
```json
"detect": {
  "files": ["requirements.txt", "pyproject.toml", "setup.py", "setup.cfg", "Pipfile", "*.py", "poetry.lock", "uv.lock"],
  "match": "any"
}
```

### Permissions

Allow rules for Python ecosystem tools:
- Interpreters: `python3`, `python`
- Package managers: `pip3`, `pip`, `poetry`, `pdm`, `uv`, `pipx`
- Test runners: `pytest`, `tox`, `nox`
- Linters/formatters: `mypy`, `ruff`, `black`, `isort`, `flake8`, `pylint`
- Build tools: `setuptools`, `build`, `twine`
- Virtual envs: `venv`, `virtualenv`

All in `Bash(tool:*)` format.

No deny rules — Python-specific dangerous patterns are covered by `_base.json`.

### Sandbox network
```json
"sandbox": {
  "network": {
    "allowedDomains": ["pypi.org", "files.pythonhosted.org"]
  }
}
```
