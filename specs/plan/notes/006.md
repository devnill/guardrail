# 006: Create sandbox default template

## Implementation Notes

Single file at `sandbox/default.json`:

```json
{
  "enabled": true,
  "filesystem": {
    "allowWrite": ["."],
    "denyWrite": ["/.git"]
  },
  "network": {
    "allowedDomains": []
  }
}
```

Key points:
- `enabled: true` — sandbox is on by default per interview decision
- `allowWrite: ["."]` — allows writes within the project directory
- `denyWrite: ["/.git"]` — prevents direct git database manipulation
- `allowedDomains: []` — starts empty; populated during merge from stack modules that define sandbox.network.allowedDomains
- The init skill reads this template, then unions in allowedDomains from each selected stack
