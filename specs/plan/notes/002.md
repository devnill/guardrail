# 002: Create _base.json stack with universal defaults and deny list

## Implementation Notes

`_base.json` is the foundation stack — always included regardless of detection results. It serves two purposes:

1. **Universal allow rules** for read-only and non-destructive CLI tools that every project needs
2. **Safety deny rules** that block known-dangerous command patterns

### Allow rules (Bash format)

Common read-only tools:
- `ls`, `cat`, `head`, `tail`, `wc`, `find`, `grep`, `echo`, `which`, `pwd`, `date`

Non-destructive file operations:
- `mkdir`, `cp`, `mv`, `touch`, `chmod`, `diff`

Text processing:
- `sort`, `uniq`, `xargs`, `tr`, `cut`, `tee`, `sed`, `awk`

Path utilities:
- `basename`, `dirname`, `realpath`

Environment:
- `env`, `export`, `printenv`

File reading (unqualified):
- `Read` — allows all file reads without path restrictions

### Deny rules

Destructive filesystem operations:
- `Bash(rm -rf /:*)` — recursive delete from root
- `Bash(rm -rf ~:*)` — recursive delete from home
- `Bash(rm -rf /*:*)` — recursive delete from root (alternate form)

Privilege escalation:
- `Bash(sudo:*)` — all sudo commands

Remote code execution:
- `Bash(curl * | sh:*)` — pipe curl to shell
- `Bash(curl * | bash:*)` — pipe curl to bash
- `Bash(wget * | sh:*)` — pipe wget to shell
- `Bash(wget * | bash:*)` — pipe wget to bash

Sensitive file edits:
- `Edit(//.env)` — environment files with secrets
- `Edit(//.*credentials*)` — credential files
- `Edit(//.ssh/**)` — SSH keys and config

### Sandbox defaults

```json
"sandbox": {
  "filesystem": {
    "allowWrite": ["."],
    "denyWrite": ["/.git"]
  }
}
```

### Important: detect block

Since `_base` is always included, its detect block should match everything:
```json
"detect": {
  "files": ["*"],
  "match": "any"
}
```
