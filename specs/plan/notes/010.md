# 010: Register plugin in claude-marketplace

## Implementation Notes

This work item involves changes in TWO repositories:

1. **guardrail repo** — Ensure `.claude-plugin/marketplace.json` has the correct repository URL
2. **claude-marketplace repo** (`/Users/dan/code/claude-marketplace/`) — Add guardrail as a new plugin entry

### In claude-marketplace

Add an entry to `.claude-plugin/marketplace.json`'s `plugins` array:

```json
{
  "name": "guardrail",
  "source": { "source": "github", "repo": "devnill/guardrail" },
  "description": "Automates permission allowlists and sandbox configuration for Claude Code projects",
  "version": "1.0.0"
}
```

The `source` field should match the pattern used by ideate (which uses `"source": "github"`). Verify the exact repo name — it may be `devnill/guardrail` or a different org/name.

### Prerequisites

- The guardrail repo must exist on GitHub at the URL referenced in the source field
- All plugin files (plugin.json, marketplace.json, skills, data files, README) must be committed and pushed
- The version in the marketplace entry must match plugin.json

### Process

1. Verify guardrail repo is pushed to GitHub
2. In claude-marketplace, add the plugin entry
3. Run `./release.sh sync` if applicable to validate
4. Commit and push the marketplace update
